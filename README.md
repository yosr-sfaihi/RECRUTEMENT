# Yosr Sfaihi — Recruiter Landing Page

A mobile-first, production-ready recruiter landing page with email capture, Gmail SMTP sending, QR code generation, and 4 recruiter flows (CV download, Portfolio, LinkedIn, GitHub).

**Stack:** Next.js 16 (App Router) + Tailwind CSS + Nodemailer → deployed to Vercel in one click.  
*Why Next.js?* Single repo for SSR page + API routes, zero-config Vercel deploy, built-in static file serving for PDFs.

## 1. Local Setup

### Prerequisites
- Node.js ≥ 18
- A Gmail account with 2-Step Verification enabled

### Install

```bash
cd recruiter-landing
npm install
```

### Configure environment

```bash
cp .env.example .env.local
```

Edit `.env.local` and fill in:
- `GMAIL_APP_PASSWORD` — see [Step 2](#2-gmail-app-password) below
- `NEXT_PUBLIC_SITE_URL` — `http://localhost:3000` for dev

### Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). All 4 flows work locally once you set the Gmail App Password.

## 2. Gmail App Password

> ⚠️ You must have **2-Step Verification** enabled on `yosrsfaihi@gmail.com` first.

1. Go to [myaccount.google.com](https://myaccount.google.com)
2. **Security** → **2-Step Verification** → scroll down to **App passwords**
   - Direct link: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
3. Click **Create a new App Password**
4. Name it anything (e.g. "Recruiter Landing Page")
5. Copy the 16-character password (spaces don't matter, include or remove them)
6. Paste it as `GMAIL_APP_PASSWORD` in `.env.local`

> The email will appear in your **Gmail Sent folder** exactly as if you typed it yourself.

## 3. Deploy to Vercel (free)

### Option A — Vercel CLI

```bash
npm i -g vercel
vercel
# Follow prompts: select your Vercel account, confirm project name
```

### Option B — GitHub + Vercel dashboard

1. Push this folder to a GitHub repo:
   ```bash
   git init
   git add .
   git commit -m "feat: recruiter landing page"
   gh repo create yosr-recruiter-page --public --push --source=.
   ```
2. Go to [vercel.com](https://vercel.com) → **New Project** → Import your repo
3. Framework: **Next.js** (auto-detected)
4. Add environment variables (one by one in the UI):
   | Key | Value |
   |-----|-------|
   | `GMAIL_USER` | `yosrsfaihi@gmail.com` |
   | `GMAIL_APP_PASSWORD` | `your-app-password` |
   | `NEXT_PUBLIC_SITE_URL` | `https://your-project.vercel.app` |
   | `ATTACH_CV` | `true` |
   | `LOG_SUBMISSIONS` | `true` |
   | `ALLOWED_ORIGIN` | `https://your-project.vercel.app` |
5. Click **Deploy**

> **Note on LOG_SUBMISSIONS on Vercel:** Vercel's filesystem is ephemeral. Logs write to `/tmp` on serverless functions and are lost between invocations. For persistent logging, set `LOG_SUBMISSIONS=false` on Vercel — your Gmail Sent folder already tracks every recruiter. If you want persistent logs, use a Google Sheet or PlanetScale DB (contact me for a quick guide).

## 4. Generate QR Code

After deploying:

1. Update `NEXT_PUBLIC_SITE_URL` in `.env.local` with your live URL:
   ```
   NEXT_PUBLIC_SITE_URL=https://your-project.vercel.app
   ```
2. Run:
   ```bash
   npm run qr
   ```

Three files appear in `public/qr/`:

| File | Use case |
|------|----------|
| `qr-code.png` | Digital — presentations, email signatures |
| `qr-code.svg` | Fully scalable, any size |
| `qr-print.png` | **Print on your CV** — black/white, generous quiet zone |

The QR URL includes `?src=cv-qr` for tracking.

## 5. Environment Variables Reference

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GMAIL_USER` | ✅ | — | Your Gmail address |
| `GMAIL_APP_PASSWORD` | ✅ | — | 16-char App Password |
| `NEXT_PUBLIC_SITE_URL` | ✅ | `http://localhost:3000` | Deployed URL (used by QR script) |
| `ATTACH_CV` | — | `true` | Attach CV PDF to every email |
| `LOG_SUBMISSIONS` | — | `true` | Log recruiter emails to CSV |
| `ALLOWED_ORIGIN` | — | `*` | CORS allowed origin (set to your domain in prod) |
| `RATE_LIMIT_MAX` | — | `5` | Max API requests per IP per window |
| `RATE_LIMIT_WINDOW_MS` | — | `60000` | Rate limit window in ms |

## 6. Test Checklist

Run through each flow after deploying:

### Functional flows
- [ ] **CV flow**: Tap "Download CV" → enter email → consent → submit → PDF downloads automatically
- [ ] **Portfolio flow**: Tap "See Portfolio" → enter email → submit → PDF downloads
- [ ] **LinkedIn flow**: Tap "Yosr's LinkedIn" → submit → redirects to linkedin.com/in/yosr-sfaihi/
- [ ] **GitHub flow**: Tap "Yosr's GitHub" → submit → redirects to github.com/yosr-sfaihi

### Email verification
- [ ] Email received in recruiter's inbox with correct subject
- [ ] Email appears in **your Gmail Sent folder**
- [ ] CV PDF is attached (if `ATTACH_CV=true`)
- [ ] Email body matches specification exactly

### Edge cases
- [ ] **Invalid email**: "abc@" shows validation error, button stays disabled
- [ ] **No consent**: Submit button stays disabled without checking the box
- [ ] **Send failure**: Error message shown with "Continue anyway →" link that still redirects
- [ ] **Rate limit**: More than 5 requests from same IP in 1 minute → 429 response

### Mobile / accessibility
- [ ] Scan QR code on phone → page renders correctly in portrait
- [ ] All cards tappable with finger (min 44×44px touch target)
- [ ] Modal slides up from bottom on mobile, centered on desktop
- [ ] Keyboard navigation: Tab through cards, Enter to open modal, Escape to close

### Security
- [ ] `/api/send-email` with `{ website: "bot" }` returns 200 without sending email (honeypot)
- [ ] Choice with invalid value (e.g. `"hack"`) returns 422

## 7. Customisation

- **Portfolio URL**: Currently points to the PDF in `/public/portfolio/`. When you have a live portfolio website, update `DESTINATIONS.portfolio` in [`app/api/send-email/route.ts`](app/api/send-email/route.ts).
- **Colors**: Edit CSS variables in [`app/globals.css`](app/globals.css) — `--navy`, `--cyan`, `--cyan-dim`.
- **Email body**: Edit `buildHtmlBody()` and `buildTextBody()` in the API route.
- **Rate limits**: Set `RATE_LIMIT_MAX` and `RATE_LIMIT_WINDOW_MS` in `.env.local`.
